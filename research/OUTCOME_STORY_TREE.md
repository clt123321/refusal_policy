# Outcome-to-story tree

**Rule:** outcomes choose the story; the story may not choose a new metric after the
outcome is known. Branches A–G are adjudicated in order. A later result cannot rescue
an earlier prerequisite failure.

## Decision tree

```text
START
  |
  +-- A. Does C0 establish a natural refusal-policy construct?
  |      no  -> A: stop safety/common-mode story
  |      yes
  |       |
  |       +-- B. Does matched-state evidence separate readout from mediation?
  |       |      yes -> record H2; fallback only if H1 later fails
  |       |      no  -> H2 false; H1 may continue only with valid causal atoms
  |       |
  |       +-- Are there at least two independently causal components?
  |              no  -> H1 unidentifiable; H2 fallback remains if it passed
  |              yes
  |               |
  |               +-- C. Is attack cost unrelated to activation organization?
  |               |      yes -> redundancy is not security-relevant
  |               |      no
  |               |       |
  |               |       +-- D. Does a carrier-blind finite parameter mode jointly
  |               |       |      affect components and predict lower A3 cost?
  |               |       |      yes -> minimum H1 common-mode result
  |               |       |
  |               |       +-- Only if D passes: E. Is the preregistered
  |               |              activation/security ordering reversed and confirmed?
  |               |              yes -> strongest H1 headline
  |               |
  |               +-- Only after confirmed H1:
  |                      F. randomized recipe causes crossed vulnerability -> H3+
  |                      G. recipe equivalent, predictor generalizes -> recipe-null
```

## Branch A — construct fails

**Trigger:** natural refusal fails bidirectional necessity/sufficiency, specificity,
semantic AHC, recognition/action separation, rescue, or matched-operator checks.

**Allowed claim:** the benign policy proxy exposed intervention/reference sensitivity;
a readable or steerable policy direction was not a validated natural causal carrier.

**Forbidden:** refusal carrier, causal writers, redundancy, shared fuse, tamper
durability, recipe mechanism, or safety defense.

**Action:** stop the security mechanism route. A methods/negative note is optional;
do not add metrics or recipes to rescue it.

## Branch B — representation predicts behavior but not attack

**Trigger:** C0 and a cross-model H2 mediation mismatch pass. Record H2 at this point;
it becomes the fallback headline whenever H1 is false or unidentifiable for any
preregistered reason, including fewer than two causal components or failure of the
frozen mechanism measure to predict carrier-blind A3/A4 beyond simple baselines.

**Allowed claim:** where refusal is linearly readable/steerable need not identify a
sufficient natural mediator. “It does not identify the cheapest parameter edit” is
allowed only if a separate preregistered localization-versus-editability comparison
passes; failure to predict A3/A4 alone does not establish that claim.

**Forbidden:** security redundancy or predictive durability mechanism.

**Action:** pursue only if the matched-state result replicates across operators,
modules and at least one additional model. Otherwise stop at a methodology result.

## Branch C — multiple writers, no security relationship

**Trigger:** at least two causal components exist, but independent-fault curves,
writer count/cut and finite common-mode measures do not predict utility-qualified
attack cost.

**Allowed claim:** activation-level causal redundancy is not, by itself, a useful
security proxy under the tested threat model.

**Forbidden:** common-cause failure or H1 positive.

**Action:** report a powered negative result only if attacks are calibrated and
multiple inductive biases agree. Do not search for a replacement composite metric.

## Branch D — common parameter sensitivity predicts lower cost

**Trigger:** multiple validated components tolerate matched independent faults, while
a carrier-blind finite parameter mode jointly changes them and prospectively
predicts a separately optimized A3 frontier beyond frozen baselines.

**Allowed claim:** a bounded common-mode failure mechanism links activation
organization to attack-family-relative durability.

**Forbidden:** global minimum attack cost, universal white-box vulnerability, recipe
causation, or a general learned-safeguard law.

**Action:** confirm with a mechanism-aware adaptive attack, sealed A4 and a second
backbone. D becomes mechanistic support if E also holds.

## Branch E — activation/security ranking reversal

**Trigger:** Branch D has passed, all preregistered pairs and uncertainty rules are
followed, and a model that
is more robust under the primary independent activation-fault curve is at least 2×
cheaper to breach under A3, the ordering is stable to atomization sensitivity, and
A4 confirms direction.

**Allowed headline:** **More Safety Mechanisms, One Weaker Lock** — causal activation
redundancy and adversarial parameter fault independence are distinct properties.

**Forbidden:** selecting the winner pair after attack reveal, counting a rank-only
plot as causal redundancy, or using an oracle minimum across uncharged attack
families.

**Action:** elevate H1. Treat D and H2 as explanations, not separate headline wins.

## Branch F — recipe systematically creates common-mode vulnerability

**Trigger:** after H1 is frozen and confirmed, randomized fixed-dose training produces
the preregistered crossed change: higher activation-fault robustness, higher finite
common-mode susceptibility, and lower independent A3 durability. Paired seeds and a
second backbone preserve the direction.

**Allowed claim:** the complete post-training recipe bundle causally changes the
cross-space failure structure at the specified resource dose.

**Forbidden:** isolating “objective” from all trainer/data/reward differences without
additional randomization; causal claims from behavior-matched checkpoints; mediation
if the mechanism endpoint does not change.

**Action:** H3 becomes the extension or final paper headline. Defense remains optional
and must survive re-optimized attacks.

## Branch G — recipe null, mechanism predicts

**Trigger:** H1 predicts attacks across runs/backbones, but preregistered recipe
contrasts lie inside equivalence margins or do not replicate.

**Allowed claim:** the cross-space mechanism generalizes across the tested checkpoint
panel, while the studied recipe bundles do not measurably control it.

**Forbidden:** objective-shaped geometry or training-induced vulnerability.

**Action:** publish the mechanism-general, recipe-null story; remove the objective
headline and do not proliferate recipe factors.

## Tie, censoring and null rules

- An interval crossing a preregistered equivalence margin is **unresolved**, not a
  directional result.
- A budget-censored attack is “not found by the frozen search policy within budget,”
  not “robust.”
- A utility-failing attack is a charged failed trial, not a breach.
- A result specific to A3 is named A3-family-specific if A4 disagrees.
- Failure to detect two components is “H1 unidentifiable” for a checkpoint; in recipe
  intention-to-treat analysis it remains an observed construct failure, not missing
  data.
- H2, D and E may describe different evidence levels for the same phenomenon. If E
  passes, it is the headline and the others are supporting mechanism, not extra
  independent discoveries.
- If D fails, H1 fails even if one visually striking pair appears reversed; E is not
  evaluated as a positive branch without carrier-blind common-mode prediction.

## Story freeze

Before attack reveal, record one primary and one fallback story:

1. **Primary:** E — activation-fault robustness reverses parameter-tamper durability,
   explained by a carrier-blind common-mode frontier.
2. **Fallback:** B — readable/steerable refusal coordinates do not identify sufficient
   natural mediation or editability.

If neither branch's frozen conditions pass, the correct conclusion is negative. No
new acronym, composite score, atomization, pair or defense may be introduced to make
the story succeed.
